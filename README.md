# قیمت روز 🇮🇷

سایت نمایش و پایش خودکار قیمت‌های روزانه از منابع معتبر.

## هدف
- دریافت خودکار قیمت‌ها هر روز
- ثبت زمان آخرین بروزرسانی
- پوشش ۱۰ قلم اصلی
- جلوگیری از درج قیمت ساختگی یا منبع تأییدنشده
- آماده برای استقرار روی Cloudflare

## معماری
منبع قیمت → استخراج خودکار → اعتبارسنجی → ذخیره → API → سایت

## ساختار
```text
public/       رابط کاربری
src/          تنظیمات و استخراج منابع
data/         داده‌های ذخیره‌شده
functions/    API و منطق سمت سرور
.github/      اتوماسیون و زمان‌بندی
```

منابع و استخراج‌کننده‌ها قبل از استفاده در خروجی عمومی باید اعتبارسنجی شوند.
